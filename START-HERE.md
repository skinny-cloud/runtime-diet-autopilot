# Start Here

1. Run the audit:
   ```bash
   bash scripts/claude-runtime-diet-report.sh .
   ```

2. Open `.claude/runtime-diet-card.md` — your generated Runtime Diet Card.

3. Read `docs/session-hygiene-playbook.md` for the one next-session rule to apply.

4. Share your card on X or r/ClaudeCode — the numbers surprise people.
